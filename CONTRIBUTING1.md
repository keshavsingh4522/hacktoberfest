# Hacktoberfest 2021 🎉

## About Hacktoberfest

Hacktoberfest is an annual celebration of open source software that encourages participation in the global open source community. The event grows bigger every year, bringing together developers of all skill levels to contribute to open source projects.

### Event Details

- **Duration:** October 1-31, 2021
- **Goal:** Complete 4 pull requests to earn rewards
- **Reward:** Limited edition T-shirt (first 50,000 participants)
- **Registration:** [Register here for Hacktoberfest](https://hacktoberfest.digitalocean.com/)

## How to Contribute

### Prerequisites

1. Register for Hacktoberfest 2021
2. Have a GitHub account
3. Basic knowledge of Git and GitHub

### Step-by-Step Contribution Guide

1. **Fork this repository**
   - Click the "Fork" button at the top right of the repository page

2. **Clone your forked repository**
   ```bash
   git clone https://github.com/YOUR-USERNAME/REPO-NAME.git
   cd REPO-NAME
   ```

3. **Create a new branch**
   ```bash
   git checkout -b your-branch-name
   ```

4. **Add your code**
   - Upload your code to the appropriate section
   - If the folder doesn't exist, create one for your language/technology

5. **Add your name to CONTRIBUTERS.md**
   - Edit the `CONTRIBUTERS.md` file
   - Add your name with a link to your GitHub profile
   - Format: `[Your Name](https://github.com/your-username) 💻`

6. **Commit your changes**
   ```bash
   git add .
   git commit -m "Add: Brief description of your contribution"
   ```

7. **Push to your fork**
   ```bash
   git push origin your-branch-name
   ```

8. **Create a Pull Request**
   - Go to your forked repository on GitHub
   - Click "New Pull Request"
   - Provide a clear description of your changes
   - Submit the pull request

## Community Rules

### General Guidelines

- Be respectful and welcoming to beginners and all community members
- Use appropriate language at all times
- Follow the project's code of conduct
- Help others when possible

### GitHub Contribution Rules

1. Pull requests can be submitted to any opted-in repository on GitHub or GitLab
2. PRs must contain commits you made yourself
3. Spam PRs will not be counted toward Hacktoberfest participation
4. Behavior not aligned with the project's code of conduct will result in ineligibility
5. Four approved PRs between October 1-31 are required for rewards
6. PRs must be made in any time zone during the eligible period

## Quality Over Quantity

While the goal is to make 4 pull requests, focus on making meaningful contributions:

- Fix bugs
- Add documentation
- Improve existing code
- Create new features
- Write tests

Avoid spammy contributions such as:
- Minor typo fixes in comments
- Whitespace changes
- Unnecessary file renames
